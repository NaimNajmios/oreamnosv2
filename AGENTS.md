- **Card Generator**: 17 sealed variants (`lib/domain/models/card_data.dart:104` `SparseCard` fallback) with 16 canvases dispatched via `CardCanvasDispatcher` `lib/ui/features/card_generator/widgets/renderers/card_canvas_dispatcher.dart:33` (`CardConfig` `lib/domain/models/card_config.dart:36` from `headlineScale/scrimOpacity/palette`). Schema 16 via `CardPromptManager` `lib/domain/services/card_prompt_manager.dart:47` + template-aware parsing `CardDataExtractor:24` (`template?, isRefresh`) forwarding to `IContentCurator.extractCardData(template)` `lib/data/services/curators/gemini_curator.dart:147`.
- **AI Curators**: `IContentCurator` (`lib/domain/services/content_curator.dart:25` `extractCardData(template?, isRefresh?)`) implemented by `GeminiCurator` + `OpenAICompatibleCurator` using pooled `ApiClient.dio` + `JsonCleaner.decodeIsolate` + `GenerationPromptManager`/`CardPromptManager`. `RateLimitDialog` `lib/ui/core/dialogs/rate_limit_dialog.dart:3` `suggestedFallbackProvider/currentProviderName/onRetryWithFallback` + `barrierDismissible:false` triggered from `GenerateScreen` `lib/ui/features/generate/views/generate_screen.dart:118` `ref.listen rateLimited` with `AiProvider.nextFallback:21` chain `gemini→groq→openRouter→cerebras`; inline `ErrorState:693` fallback when no model. Silent auto-fallback is VOLATILE — visitor hops via `forceProvider` + `_resolveModelId` (per-provider stored model / provider default, never another provider's selected model); the user's persisted `selectedProvider/selectedModel` survive a rate-limit burst; persistence is reserved for the explicit dialog path (`retryWithProvider`). 429 cooldown floor 60s (`_defaultCooldownMs`) + combined share attempt budget `_maxAttemptsPerShare = 4` (`_canAttemptMore`).
- **Share Intent**: `ShareIntentService` `lib/data/services/share_intent_service.dart:1` — `initialize()` MUST NOT `reset()` before `getInitialMedia()` (purging first kills the fresh cold-start share). Delivery order: `getInitialMedia` → load persisted fingerprint (`share_initial_fingerprint` pref) → `handleSharedMedia(isInitial: true)` → `reset()`. Fingerprint (`normalizeDedupKey`) guards stale replay from Android's cached process; 1500ms window dedup unchanged; `app.dart` `_inFlightShareContent` pin expires after 8s.
- **Vision Extraction**: $0 cloud chain `VisionCuratorChain` `lib/data/services/vision_curator_chain.dart:23` (`extractStructured(cancelToken:)`, `FreeTierGuard` skip-at-cap, `VisionModelAllowlist` blocks paid/retired models — 2.5-flash-lite floor). - **Secrets**: `PreferencesService` (`lib/data/services/preferences_service.dart`) stores API keys in `flutter_secure_storage` + prefs in `shared_preferences`. Never log keys.
